# UKR.NET Mail MCP

A planned local MCP integration for UKR.NET mail, intended for use with Codex, Claude, and Cursor. The project is in the specification stage; there is no installable server yet.

The intended design connects directly to UKR.NET over IMAP and SMTP, keeps credentials on the user's device, and requires enforceable approval before sending. Client support and security guarantees must be tested before release.
